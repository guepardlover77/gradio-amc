# gradio-amc

Interface web Gradio pour [Auto Multiple Choice](https://www.auto-multiple-choice.net/) (AMC), dockerisée et utilisable depuis n'importe quel OS.

Voir la documentation complète dans [`docker-gradio-amc/README.md`](./docker-gradio-amc/README.md).

## Démarrage rapide

```bash
cd docker-gradio-amc
chmod +x install.sh && ./install.sh
# → http://localhost:7860
```
